# Java Coding Practice - Fundamental Challenges

This repository contains Java solutions to common fundamental coding challenges. Each problem is designed to strengthen core skills in logic building, control flow, string/number handling, loops, recursion, and basic algorithms.

## 📁 Folder Structure

Each Java file in the `assessments/` directory is paired with a corresponding problem statement in `problem_statements/`.

**Structure:**

- `assessments/`  
  ├── Armstrong.java  
  ├── PalindromeChecker.java  
  ├── EvenOrOdd.java  
  ├── PrimeNumber.java  
  └── ...

- `problem_statements/`  
  ├── Armstrong_problem.txt  
  ├── PalindromeChecker_problem.txt  
  ├── EvenOrOdd_problem.txt  
  ├── PrimeNumber_problem.txt  
  └── ...

## 🚀 How to Use

1. Clone this repository or download it as a zip.  
2. Open the project in your Java IDE (Eclipse, IntelliJ, etc.) or use the terminal.  
3. Browse `assessments/` for Java source files.  
4. Match each file with its description in `problem_statements/`.  
5. Compile and run:

```bash
javac assessments/PalindromeChecker.java  
java assessments.PalindromeChecker
```
