Problem: Armstrong Number Checker

Write a Java program that checks whether a given positive integer is an Armstrong number.
- An Armstrong number is one where the sum of its digits, each raised to the power of the number of digits, equals the number itself.
- Do not use string conversion or arrays to extract digits.
- Input should be validated to ensure it's a positive integer.

Example:
Input: 153 → Output: Armstrong
Input: 123 → Output: Not Armstrong
